# Copy changes

Where the website copy differs from the source text, and why.

---

## More than a HubSpot setup — intro paragraph

**Source**
> A CRM implementation shouldn't start with creating properties and pipelines.
>
> It starts with questions:
>
> [the five questions]
>
> We map the answers first. Then we build the system.

**Website**
> A CRM implementation shouldn't start with creating properties and pipelines. It starts with questions — and we map the answers before we build the system.

**Why:** the five questions sit in their own column next to the intro, so the
lead-in and the closing line were joined into one paragraph beside them.

---

## What we implement — Data migration + Integrations merged

**Source** — two separate items:

> **Data migration**
> Moving data from your existing CRM, marketing tools, spreadsheets or other sources — including mapping, cleaning, migration and validation.
>
> **Integrations**
> Connecting HubSpot with ERP systems, websites, telephony, prospecting platforms, configurators and other business-critical tools.

**Website** — one item:

> **Data & Integrations**
> Moving data from your existing CRM, marketing tools or spreadsheets — mapping, cleaning and validation — and connecting HubSpot with ERP systems, websites, telephony and other business-critical tools.

**Why:** the grid is three columns, so seven items left one alone on the second
row. Merging these two gives six, which fills the grid evenly.
